# didie111.github.io

브라우저 RTS: [공개 게임](https://didie111.github.io/rts/)

SC1.17은 F10 창을 화면 왼쪽 중앙의 두 칸 구성으로 열고, 제목줄을 드래그해 이동할 수 있게 합니다.
F10·마우스 고정 버튼은 하단 유닛 정보 패널의 중앙 위에 배치합니다.
SC1.16의 일꾼 반복 감속 수정, 대량 병력 최적화, 마우스 고정/Esc 해제와 패널 아래 화면 이동 띠를 유지합니다.
SC1.15의 회전·가속·비비기와 Hold·시즈·에그의 규칙은 유지합니다.
전체 이동 조건과 성능 검증은 [SC1.16 기록](rts-src/docs/sc116-movement-performance.md)에 있습니다.
원작 재현 코드의 적용 범위와 영상 관찰은 [조사 기록](rts-src/docs/sc1-collision-research.md)에 있습니다.
