# STARCRAFT 1 스타일 RTS (테란 vs 저그)

브라우저에서 바로 실행되는 스타크래프트 1 모방 RTS. 외부 이미지/사운드 없이 캔버스로 절차적 생성한 픽셀 그래픽과 WebAudio 효과음을 사용한다.

- 플레이: `https://didie111.github.io/rts/`
- 소스: `rts-src/src/` (HTML + CSS + JS 여러 파일)
- 빌드 결과: `rts/index.html` (단일 파일, 직접 수정하지 말 것)

## 빌드

```bash
python3 rts-src/build.py
```

## 이동 / 충돌 검증

```bash
node --test rts-src/tests/*.cjs
```

시즈 모드·시즈/해제 전환 중인 탱크, 에그, 버로우·락다운 상태는 물리 처리로 좌표가 바뀌지 않는다.
이동 유닛은 정지/Stop/Hold 유닛을 우회하고, 통과 공간이 없는 길목에서는 멈춘 뒤 기존 막힘 재탐색을 사용한다.
양쪽 모두 이동 중이면 서로 분리되며, 스폰 등으로 이미 겹친 일반 대기 유닛은 겹침만 해소한다.
채취 중 일꾼의 충돌 예외와 공중 유닛 처리는 유지한다.
이는 원작 엔진을 그대로 이식한 것이 아니라 현재 게임의 이동 시스템에서 해당 동작을 구현한 것이다.

브라우저 수동 확인: F10으로 AI를 끄고 탱크를 시즈 모드로 둔 뒤 마린/벌처 여러 기를 반대편으로 이동시킨다.
탱크는 제자리에 있고 이동 유닛이 양옆으로 지나가는지, Stop/Hold 마린도 밀리지 않는지 확인한다.
탱크의 시즈 해제 후에는 다시 이동할 수 있어야 한다.

## 소스 구성 (로드 순서)

| 파일 | 내용 |
| --- | --- |
| `data.js` | 테란/저그/프로토스 유닛·건물·연구·스킬 데이터 (원작 수치 기반) |
| `content.js` | 확장 유닛/건물/부속 건물/능력 데이터 및 버전 |
| `map.js` | 128×128 대칭 1v1 맵 생성, 지형/언덕/램프, 자원, 크립, 파일런 전력 |
| `path.js` | A* 길찾기, 공간 해시 |
| `game.js` | 월드 상태, 자원/인구수, 시야/탐색/디텍션 |
| `entity.js` | 유닛/건물 로직: 이동, 채취, 건설, 생산, 수송, 대기/반격/자동 교전, 버로우·시즈 등 |
| `combat.js` | 무기, 투사체, 스플래시, 크기별 데미지 배율, 스킬 |
| `commands.js` | 명령 처리(스마트 우클릭, 어택땅, 정찰, 홀드), 물리, 게임 틱, 승패 판정 |
| `art.js` / `render.js` | 절차적 스프라이트, 지형, 안개, 이펙트 렌더링 |
| `sound.js` | 합성 효과음 |
| `ai.js` | 저그 AI (경제, 건설, 연구, 방어, 공격 웨이브) |
| `ui.js` | 드래그 선택, 커맨드 카드, 미니맵, 단축키, 부대 지정, 테스트 패널 |
| `main.js` | 시나리오 설정(1시 테란 / 7시 저그), 메인 루프, 승패 화면 |

## 테스트 패널 (F10 또는 `)

적/아군 유닛·건물 스폰, 적 웨이브 즉시 출격, 적 AI on/off, 전체 맵 공개, 저그 진영 직접 조작, 자원 추가, 빌드/게임 속도 조절, 샌드박스 모드.

## SC1.2 개선 (2026-09-30)

- 지상 정지 유닛을 강제로 밀지 않는 충돌 처리. Hold는 사거리 밖 적을 추격하지 않고, Stop은 현재 명령을 취소한 뒤 대기/자동 교전으로 돌아간다. 이동/어택땅/정찰 그룹은 같은 목적지를 받는다.
- 테란 부속 건물: 컴샛, 머신숍, 컨트롤 타워, 코버트 옵스, 피직스 랩, 뉴클리어 사일로. 연결 위치와 생산/연구 조건을 검사한다.
- 누락 유닛 추가: 발키리, 퀸, 가디언, 디바우러, 인페스티드 테란, 아콘, 다크 아콘, 리버, 아비터. 각각의 자체 스프라이트와 생산/변태/합체 경로를 제공한다.
- 퀸의 패러사이트/인스네어/브루들링/감염, 아비터 클로킹/리콜/스테이시스, 다크 아콘 피드백/메일스트롬/마인드 컨트롤, 커세어 웹, 메딕 실명, 템플러 환상, 핵 공격, 실드 배터리 충전.
- 캐리어 인터셉터/리버 스캐럽은 비용을 지불하고 생산해야 한다. 초기 탄약 0, 수량/연구 용량 검사.
- 영구 클로킹·패러사이트 시야·스캔 탐지, 투사체 도착 시 EMP, 잘못된 시전 대상의 에너지 소모 방지, 빈 공간을 확인하는 수송 하차.
- 기본 배치: 1시 테란 커맨드 1, 배럭 1, 마린 4, 서플 2, SCV 10. 7시 저그 해처리 3, 저글링 10, 히드라 10. AI 경제/인구수 운영용 드론 4, 오버로드 2, 해처리별 라바도 배치한다.
- F10: 세 종족의 유닛/건물 스폰, 적군 직접 조작, 자원/연구 치트. 상단 SC1.2와 패널의 전체 버전으로 업데이트 확인 가능.

이동은 원형 충돌체·타일 A*·국소 우회이며 OpenBW의 사각 충돌체/이동 상태 머신 전체와 다르다.
스캐럽의 지상 추적/막힘과 캐리어 인터셉터의 개별 체력/격추/복귀 수리는 간소화했다.
핵 유도·광역 효과·변태/합체 애니메이션과 일부 시간/업그레이드는 자체 구현이다.
자원·인구수는 플레이어별 공용 풀이고 종족을 빼앗은 경우의 원작 종족별 인구 제한은 분리하지 않았다.
적 AI는 저그 경제·방어·공격 웨이브를 수행하는 자체 AI이며 원작 AI/전 종족 캠페인/네트워크 멀티플레이는 포함하지 않는다.

검증은 실제 시뮬레이션 모듈을 실행하는 회귀 테스트, 세 맵 시드의 시작 배치·채취/AI 진행,
전체 유닛·건물 스프라이트/명령 카드 및 맵 렌더링으로 수행한다.

## SC1.3 지상 명령/경로 수정 (2026-09-30)

- 대기 유닛의 임의 방향 회전 제거. Stop/Hold 유닛은 위치와 방향을 유지하며 적 획득 규칙에 따라 교전한다.
- 정지 유닛 무리에 막히면 유닛 장애물을 반영하여 경로를 재탐색한다. 도달 불가능한 목적지는 통과 가능한 경로 끝에서 정지한다.
- Move/공격 이동 구분, Hold 사거리 제한, 은폐 고스트의 Guard 자동 교전 억제를 회귀 검증한다.
- OpenBW의 속도/공격 간격 수정 공식을 참고하여 스팀·인스네어 상쇄, 산성 포자, 저글링 아드레날 업그레이드와 공격 간격 분산을 반영한다. 스포닝 풀의 아드레날 연구는 하이브를 요구한다.
- 기존 시작 배치와 세 종족 기능을 유지한다. 충돌체와 길찾기 전체는 여전히 자체 엔진이다.

## SC1.4 끼임 복구 및 시작 배치 (2026-09-30)

- 건물/지형/자원 모서리에서 원형 물리 판정과 사각 경로 판정이 서로 달라 모든 이동 후보가 거부되던 문제를 수정했다. 이제 동일한 원-타일 판정과 반경을 사용한다.
- 시작 유닛 생성 시 중심 타일만 검사하던 방식 대신 몸체 전체와 기존 유닛 간격을 검사한다. 시작 마린 4기, SCV 10기 등의 수량은 그대로다.
- 정체 시 8px 국소 경로로 실제 유닛 사이를 탐색하며, 큰 우회에는 기존 타일 경로를 사용한다. 동적 장애물에 의해 경로가 끊긴 경우 이동 명령을 완료 처리하지 않는다.
- 촘촘한 경로의 회피/경유점 도착 처리와 실패 시 재탐색 간격을 조정했다. 탐색은 범위/노드 수/프레임 예산으로 제한한다.
- 모서리 탈출, 새 명령, 혼합 병력 30기의 재집결/분산, 막힌 통로 재개, 3개 맵 시드의 시작 마린 4기 이동을 시뮬레이션으로 검증한다.
