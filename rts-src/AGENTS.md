# RTS 소스 작업 전 필독

반드시 저장소 루트의 [`AGENTS.md`](../AGENTS.md)와 [`AI_HANDOFF.md`](../AI_HANDOFF.md)를 전체 읽고 시작한다. 이 디렉터리의 실제 소스와 검사를 변경하고 `build.py`로 배포 파일을 생성한다.

스타크래프트 1 공개 구현의 실제 함수·조건·수치를 직접 비교한다는 최우선 원칙, 비비기/채취/고정 몸체 규칙, SC1.20의 F10 중 실제 마우스 고정 유지, 24기 선택 및 대량 유닛 성능을 보존한다. 상세 상태를 오래된 버전 문서만 보고 판단하지 않는다.
