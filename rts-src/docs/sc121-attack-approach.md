## 문제와 변경

SC1.20의 `engage`는 사거리 밖 병력을 같은 표적 중앙으로 보냈다. 건물 내부가 막혀 경로 탐색이 바깥 끝점을 얻어도 `moveTo`의 움직이는 표적 처리에서 그 끝점을 다시 중앙으로 덮어쓸 수 있었다. 이미 앞줄이 공격하더라도 뒷줄은 같은 중앙으로 다시 접근·회피·재탐색했다.

`moveInAttackRange`는 정지한 지상 근접 표적을 따로 처리한다. 먼 거리부터 공격 경계 방향으로 접근하여 열린 지형에서도 중앙을 목표로 A*를 반복하지 않는다. 경계 거리 6타일 안에서는 `moveToMeleeBorder`가 네 면의 공격 가능한 후보를 만들고 현재 몸체·지형·다른 접근 목표를 검사한다. 도달 가능한 가까운 후보를 유지하고 실제 사거리 안에 들어가면 예약을 해제하고 기존 무기로 공격한다.

가까운 빈 후보가 벽 안쪽에 갇혀 있으면 다음 재시도에서 다른 후보를 검사한다. 타일 경로가 완성돼 있는데 국소 경로만 부분 경로로 끝나는 경우도 수정했다. `PF.unitPath(requireGoal=true)`는 부분 끝점을 완전 경로로 오인하지 않는다. **일반 이동/기존 비비기의 짧은 부분 경로는 기본 분기에 그대로 남겨 두었다.**

표적별 미진입 근접 공격자 집합을 관리한다. 32기를 넘으면 2,000 탐색 작업/틱을 공유하고 개별 탐색에도 남은 예산을 적용한다. 거친 타일 경로가 유효하면 먼저 사용하되 모든 구간의 지형·정지 몸체를 검사한다. 직접 통행은 즉시 처리하며 실패/예산 대기는 분산해 재시도한다. 이미 공격 중인 유닛의 자리, 정지/Hold/고정 몸체를 밀어 만들지 않는다.

**경계 후보/예약, 원형 충돌 수치, 탐색 예산은 이 자체 엔진에 적용한 구현이다. OpenBW에 동일한 원형 슬롯·32기/2,000 규칙이 있다는 뜻이 아니다.** 같은 입력으로 OpenBW를 실행해 프레임마다 동등성을 확인한 단계도 아니다.

## UI 동작

- FPS: `GAME.performance.fps`의 기존 rAF 집계를 화면 상단에 표시한다. 초기 측정 전은 `FPS —`. 별도 매 프레임 타이머나 시뮬레이션 속도 변경은 추가하지 않는다.
- 스폰 목록: 목록별 `WeakMap`에 선택 값/실제 `scrollTop`을 저장한다. 선택·밖 클릭·F10 닫기 뒤 다시 열어도 같은 위치다. 외부에서 선택 값이 달라졌으면 새 선택을 보여 준다. 현재 페이지 세션에서 기억하며 새로고침 후 영구 저장은 이번 요청 범위가 아니다.
- 미니맵: 이미 정사각형인 외곽 미니맵 대신 **안의 흰 카메라 표시**를 정사각형으로 변경했다. 카메라의 보이는 중심과 큰 축 길이를 사용하고 지도 가장자리에서 안으로 보정한다. 실제 게임 화면의 넓은 가로세로 비율은 유지하므로 표시 박스가 실제 화면 경계 전체와 정확히 일치하는 것은 아니다.
- F10/F1 중 실제 Pointer Lock 유지, 가상 커서 조작, 24기/건물 선택, HUD 중앙 메뉴·하단 화면 이동 띠는 보존한다.

## 검증

`node --test rts-src/tests/*.cjs`: **415/415 통과**. 추가 공격 검사 21개는 실제 엔진·명령·물리·피해를 실행한다. 24 저글링 네 방향, 첫 공격 시간, 실제 피해, 속도/새 겹침/지형 침범 제한, Hold 아군이 막은 면, 열린 먼 면, 갇힌 가까운 빈 후보, 이동 표적, 질럿/다크 템플러/파이어뱃/울트라/세 종족 일꾼, 마린/드라군/뮤탈/레이스/스카웃, 이동 공중 표적을 검사한다.

SC1.20 소스로 동일 공격 검사를 실행했을 때 네 방향의 초기 진입 검사가 모두 실패했다(당시 공격 검사 18개 중 4개 실패). 마지막 목록 위치·개별 목록 독립 위치·미니맵 중심/가장자리/배율 검사도 추가했다. 자동 고정 검사는 DOM 대역을 사용하며 실제 OS Pointer Lock 실행 증명과 구분한다.

재현 벤치마크: [`../scripts/attack-benchmark.cjs`](../scripts/attack-benchmark.cjs). 평지, 시드 42, 체력 100,000 커맨드센터 `(24,24)` 타일, 좌측 4열/20px·행간 22px 저글링에 명시적 공격. 실제 공격/피해를 유지하고 고체 표적이 일찍 파괴되지 않게 했다. 두 버전은 같은 기기에서 별도 프로세스로 순서대로 실행했으며, 아래 400기 비교는 각 버전 세 번이다. 다른 검사/벤치마크를 동시에 돌린 중간 실험은 최종 수치에 포함하지 않았다.

## 남은 원작 차이·수동 확인

사각/고정소수점 몸체와 현재 원형/실수 좌표 차이, 모든 이동 상태·공격 발사각/정지 관성·iscript 발사 시점, 근접/Scourge의 세부 앞지르기 타이머, 공중 겹침/분산의 원작 동등성은 추가 비교가 필요하다. 원격 Chrome의 실제 Pointer Lock 거부 이력도 남아 있으므로 고정 상태의 실제 로컬 브라우저 F10/F1 입력은 별도로 확인한다.

GitHub Pages `37044435305` 성공 후 공개 SC1.21 화면을 확인했다. 실제 선택/메뉴 조작으로 다크 템플러 818px, 팩토리 1366px 목록 위치 재개방 일치를 확인했다. FPS 상시 표시와 정사각 미니맵, 아군 저글링 24기 스폰·24/24 선택·적 커맨드센터 공격·파괴 결과도 확인했다. 원격 Chrome에서 관찰한 FPS는 1이므로 이 UI 확인을 고주사율/대량 렌더 성능 증명으로 쓰지 않는다. 공격 진입 시간 수치는 위 자동 시뮬레이션 결과다.
