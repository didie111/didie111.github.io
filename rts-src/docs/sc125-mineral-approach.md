# SC1.25 미네랄 접근 경로 (2026-10-03)

기준은 SC1.24의 `e10b3af9e3d281a414145d9ee16d32fd6c3d019d`다. SC1.24는 광맥 배치만 연결했으며, 일꾼의 광맥 중앙 접근은 그대로였다. 사용자가 배포 후에도 뒤로 돌아 채취하는 문제를 보고해 채취 접근을 수정했다.

## 원인과 비교

`gatherLogic`가 점유된 광맥 중앙을 `moveTo`에 전달했다. `PF.find`는 막힌 목표를 `nearestPassable`로 치환하는데, 그 선택은 목표 주변 타일 순서/거리만 사용한다. 광맥 아래에서 출발해도 위쪽 타일이 선택되거나, 세로 광맥의 가까운 왼쪽 면보다 오른쪽 면이 선택될 수 있었다. 또한 `moveTo`는 건물 경계의 경로 끝점을 중앙으로 다시 덮어쓰는 분기를 가지고 있다.

연결된 8개 광맥의 중앙 필드 `(864,656)`과 SCV 시작 `(864,836)`의 같은 입력에서:

| 결과 | SC1.24 | SC1.25 |
| --- | --- | --- |
| 첫 채취 위치 | `(821.22,634)`, 반대쪽 위 | `(864,682)`, 접근한 아래쪽 |
| 첫 채취 틱 | 156 | 46 |
| 실제 누적 이동 | 525.66px | 157.18px |

Node VM에서 실제 게임 틱/이동을 실행한 재현이다. 브라우저 FPS나 원작 실행의 동일 입력 결과와 혼동하지 않는다.

## 읽은 원본과 적용

OpenBW 고정 커밋 [`4b046d5f65302b10cb0a745f0fecd37ec85b20a8`](https://github.com/OpenBW/openbw/blob/4b046d5f65302b10cb0a745f0fecd37ec85b20a8/bwgame.h)의 실제 함수들을 확인했다.

- `unit_pos_is_bordering_target`, `move_to_target`, `move_to_target_reset` (2012–2041행): 기존 도착점이 대상 경계면이면 유지하며 광맥 중앙 좌표로 매번 교체하지 않는다.
- `order_MoveToMinerals` (4278–4368행): 채취 충돌 상태로 접근하고, 다른 일꾼이 캐는 광맥이면 다른 필드를 검사한다. 도착한 뒤 대기/채취 명령으로 전환한다.
- `wait_for_resource`, `try_gather_resource`, `order_MiningMinerals`: 자원 점유/대기와 채취 상태를 분리한다.

적용 위치는 `Entity.moveToMineral`, `mineralApproach`, `gatherLogic`다. 광맥 주위의 실제 작업 가능한 점을 검사하고, 직선 또는 도착점까지 완성된 경로만 채택한다. 후보들을 실제 경로 길이로 비교하며 경로의 끝을 작업점으로 유지한다. 고립된 가까운 후보에 경로 예산을 다 쓰면 다음 재시도는 미검사 후보부터 진행한다. 도착 여부는 실제 광맥 경계 거리로 확인하므로 부분 경로나 경로 실패로 원격 채취를 시작하지 않는다.

경계 후보의 8px 간격, 원형 일꾼의 충돌 반경, 경로 예산/재시도는 자체 엔진에 맞춘 적용이다. OpenBW 전체 길찾기·사각 몸체·원작 프레임별 동등성을 이식/검증했다는 의미가 아니다. 어느 면에서든 채취할 수 있으며, 가까운 면이 막혔으면 다른 접근 가능한 면을 사용할 수 있다.

접근점은 채취 이동 동안 유지하고, 반납 후에는 현재 위치에서 다시 선택한다. 목표 광맥 교체, 접근점 점유 또는 이동 정체에도 다시 선택한다. 일반 이동·공격·가스·반납 엔진과 광맥 배치는 변경하지 않았다.

## 검증

```bash

python3 rts-src/build.py
git diff --check
```

- 새 채취 검사 **17개 통과**, 전체 **441개 통과**.
- SCV/드론/프로브 각각 위·아래·왼쪽·오른쪽에서 연결된 광맥의 가까운 면을 채취하며, 이동량/지형 충돌/실제 도착을 검사한다.
- 고립된 가까운 작업점보다 접근 가능한 다른 면을 선택한다. 완전 봉쇄는 원격 채취 없이 명령을 유지하고, 열린 뒤 재개한다.
- 선택한 작업점이 건물로 막히면 다른 점을 찾는다.
- 현재 맵의 양쪽 본진/확장 8개 기지, 광맥 64개를 세 종족 일꾼으로 각각 본진 쪽에서 접근한다.
- 실제 시작 시나리오의 SCV 10기가 본진 쪽에서 채취하고 실제 자원을 반납한다. Stop 전환 시 채취 충돌 예외를 해제한다.
